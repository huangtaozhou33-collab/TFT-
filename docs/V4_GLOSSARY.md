# V4 第一阶段：中文社区术语

2026-10-11 接入用户提供的 184 条术语，保留原有且未被覆盖的经济、战力、节奏、追二、站位、装备消化、备战席 7 条，共 191 条。应用版本为 4.0.0。本次交付是词库、检索与问答输入链路的开发完成，不是对真实模型回答准确率的全量证明。

## 内容与来源

唯一词库源文件为 [`data/glossary/zh-CN.v4.json`](../data/glossary/zh-CN.v4.json)。用户条目保留术语、别名、分类、适用范围、释义、消歧边界、示例问答、证据标签和参考链接。184 条覆盖 14 个分类；其中 71 条原标记为 `source_supported`，113 条为 `editorial_common_usage`。7 条保留项另标记为项目编者整理。

`source_supported` 表示材料提供了用法或概念参考，不表示官方定义。本次未逐条打开复核链接，所有条目都有 `verificationStatus: not_independently_verified`。来源不明的条目不伪造网址、采集时间或游戏补丁。全部词条使用 `scope: general`、`sourcePatch: null`，历史/赛季相关说明保留在卡片、检索片段及模型输入中。

## 进入 AI 的路径

`getPublishedGlossary` → 术语匹配 → `search_knowledge` → Chat 证据适配 → 模型上下文。数据库模式使用当前已发布词库，本地模式使用 JSON；不会只升级路由词典，却让检索仍读旧发布。每个词条是一份文档和一个片段，标题与引用编号有显式映射。

- “速八”“卡牌”“启动”有独立的义项 ID。语境提示只调整候选顺序，不全局替换玩家原话；截断候选时显式标记。
- 较长词优先，避免把“大天使”拆成“天使”、把“破甲弓”拆成“破甲”和“弓”。ASCII 边界保护 TF、95、主C 等短词。
- “攻速、护甲、魔抗、拳头”只有组件语境才匹配组件卡；词条仍明确属性与组件不是同义词。
- 支持“吃3息”“D两下”和阶段回合表达，不把这些词推成固定金币门槛、刷新次数建议或升级时刻。
- 用户提供的确切示例问句可召回对应卡片；这不代表已覆盖所有改写。词库搜索会搜索定义与相关词，所以页面搜索“速八”还会显示相关的“拉人口”；AI 的词义匹配则使用独立的长词/歧义逻辑。
- 20 个英雄正式名称与昵称映射离线生成到 `public/glossary-aliases.js`，只附加到当前目录真实存在的英雄。不会仅凭历史昵称创造赛季实体、费用、羁绊或 ID。
- “吃分就是进前四吗”等纯释义问题不继承页面旧筛选条件；明确统计、强化机制、法杖和转职问题仍保留原专用检索路径及工具预算。

卡片及提示词要求模型区分词义与当前事实。装备的效果、配方、英雄当季存在性、阵容强度和统计必须另查对应版本的资料；术语卡不能支持这些结论。

## 维护方式与限制

修改 JSON 后运行 `node scripts/sync-glossary-aliases.mjs` 更新生成的英雄别名，再运行测试、导出种子包。匹配与检索修订哈希由词条内容计算；检索缓存版本已提升，避免复用旧语义结果。若种子包变化使归档规则绑定失效，必须核对被影响的原快照再更新绑定，不能仅修改 releaseId 来绕过完整性检查。

目前是确定性词形与有限语境识别，不是完整中文语义解析。输入省略、反讽、圈内新外号、跨句属性语境仍可能需要澄清。没有通过本次离线测试声称真实模型会始终引用正确或完整遵循边界；当前提供商的端到端回答质量尚未重新验收。

修改前文件保存在忽略目录 `tmp/v4-before/`，未执行 Git 重置、清理、提交或删除数据。恢复数据包时应成对恢复种子包、manifest 与归档规则绑定，避免交叉版本。
