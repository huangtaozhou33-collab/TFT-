## 原生展示与助手

- 资料库首页有分类入口、中文全文搜索、英文别名搜索与常用速查。
- 海克斯卡片标记有奖励／交互细则，可筛选这些卡片；点击进入详情查看条件与原生中文奖励表。
- 多表专题可选择档位，长表可搜索，羁绊天梯可按羁绊数量筛选。概率口径与条件独立显示。
- 表内英雄／装备可点开当前图鉴；法杖细则可回到对应精确形态的法杖详情。
- 机制页面链接保留 `topic`，可刷新恢复当前专题。全局搜索也包含规则资料。
- 助手使用 `get_library_knowledge`，服务端重查专题或实体；浏览器提交的表格值不作为证据。描述、奖励与出现条件有独立引用。
- 开发者模式列出中文机制发布包与切片，保留原始来源和检索资格。存储仍为本地 JSON，没有声称已连接 MySQL、Milvus 或向量检索。

## 同步与维护

`scripts/library-facts.mjs` 是图片核对后的中文事实；`library-rules.mjs` 整理 CSV 条件和法球交互；`library-descriptions.mjs` 保存核对后的中文描述。`library-reviewed-sources.json` 锁定本次复核的页面、图片和 CSV 哈希。

`npm run sync:library` 默认复用已通过校验的当前版本；`--force` 从本地采集重建；`--from=目录` 指定采集目录。发布先写不可变 JSON，再原子更新 manifest。来源发生变化、英文条件未翻译、概率／表格校验不通过时停止，不覆盖已生效的包。`npm run sync:knowledge` 也包含这一来源。

公开采集辅助脚本 `scripts/capture-reference.mjs` 将研究输入保存到已忽略的 `tmp/v3-reference`；新一轮采集后必须核对内容并显式更新审核锁。已发布的中文包随项目保留，可离线读取，不要求重新下载源图片。

验证包括完整项目测试、版本／哈希隔离、条件概率、精确变体、参考资料检索隔离、中文描述引用、HTTP 压缩，以及浏览器实际操作。原站没有提供的物品概率、单位池概率、版本适用性或条件不补写。
