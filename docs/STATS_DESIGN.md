# 大数据分区与版本知识库

> 本文保留早期统计设计和演进记录。当前数据库版首页、大数据、筛选器与 Agent 共用 MetaTFT；段位、光明、散件、存储粒度和未完成项以 [V4 数据架构](DATABASE_ARCHITECTURE.md) 为准。

本次调整按用户要求将机制图鉴与统计研究分开：图鉴回答“是什么、有什么效果、如何合成”，大数据回答“来源样本中表现如何、谁适合穿、哪些队友与三件套表现较好”。

## 对标与范围

核查日期为 2026-10-08（Australia/Sydney）。[Tactics.tools](https://tactics.tools/explorer) 将统计与赛季资料分开，提供条件探索；其[装备页](https://tactics.tools/items) 区分常规、神器、纹章与光明等类别，展示均次、前四、登顶和持有者。[MetaTFT 英雄页](https://www.metatft.com/units/Camille) 将三件套、单件装备与阵容关联放在同一实体下。

本机统计中心据此独立提供阵容、英雄出装、装备适配、转职研究和羁绊档位，支持搜索、指标排序和最低样本数筛选。按用户确认，强化符文保留机制图鉴，不设统计排行。OP.GG 公开 TFT 工具未提供羁绊聚合指标，因此羁绊采用 [Tactics.tools 公开羁绊页](https://tactics.tools/traits) 内嵌的实际档位统计，每版本集中保存一次。

当前英雄视角是**具体出装组合的统计**，装备视角是**持有该装备的英雄统计**。不能把排名最好的三件套当作英雄的总体均次，也不能把多个组合的分母随意相加。当同一装备有多个组合时，直接按来源记录比较，不伪造全队提升率。

羁绊统计独立保留 Tactics.tools 的 Patch 18.4、Ranked / Diamond+ 样本口径，逐个来源档位映射实际羁绊人数。其样本规模、时间和补丁不套用给 OP.GG，也不能把高档位的观测表现说成升级该羁绊的因果收益。

## 按版本录入

网页与 Agent 不发起 OP.GG 请求。单独的同步命令负责首次集中录入，每个已发布缓存带版本上下文、源记录、采集时间和哈希校验；知识库以文件保存，并由站内工具直接查询。

同版本默认跳过更新。补录缺失实体与强制重录是明确的维护动作；一批新记录校验完成后才原子切换发布指针。中途断网不损坏上次成功的知识库。

缓存不因过了 24 小时而自动失效或联网。赛季、资源版本或规则发生变化后，旧缓存不能悄悄混入新上下文。用户可浏览当前固定版本数据；版本更新后再集中录入新包。

OP.GG 未提供的统计补丁仍是未知。资产版本、配方响应版本和统计补丁分开记录，不借其它响应的版本号伪装统计版本。

## 回答方式

问英雄的阵容与出装时，默认先给结果：

> 阵容：阵容名；队友列表。[来源]
>
> 装备：三件装备。[来源]

“最佳”默认只在已缓存候选中按平均名次比较，并优先采用足够样本的记录；少样本、未收录或仅有阵容示例时加一句必要说明。详细机制、时间与统计口径只在用户继续询问时展开。大树按茂凯识别。

## 转职研究

纹章通过来源显示名称与当前羁绊做精确映射；这种映射确认了羁绊身份，不等于验证了全部穿戴兼容规则。统计页可以比较携带者，再让 Agent 直接列队友。

优先返回来源中同一个英雄确实携带该纹章的阵容。没有匹配阵容时，以当前英雄标签和羁绊档位提供 8 人模拟名单，明确标记“模拟搭配”，不附实测胜率；不会改变用户草案或凭空增加库存。模拟不会重复选同一英雄的多个形态，也不会给本来已有目标羁绊的英雄重复添加转职人数。

纹章本身占一个装备槽，Agent 推荐整套装备时包含纹章在内最多三件；没有对应纹章出装记录时保留缺失说明，不把普通三件套再加一个纹章。

本次仅调整现有 Agent 提示词与工具取数逻辑，没有引入 Jev。

## 赛季特殊玩法与攻略评级

特殊玩法采用独立赛季入口，目前收录 Set 18 Wisps（法杖／自然仙灵）。规则、实际法杖效果和升级变体进入版本缓存；网页与 Agent 共用只读知识库。出现阶段、费用或条件未收录时保持未知，不用源数据的数值 tier 冒充推荐等级。

法杖 S–D 来自 [MetaTFT 的 Spencer 专家榜](https://www.metatft.com/wisp-tiers)，属于职业选手攻略判断，不是胜率统计。此次公开页面核验 174 个基础法杖名称，按精确英文名称映射；未匹配项、升级与棱彩变体保持未评级。榜单未给出确切游戏补丁或绝对更新时间，保留未知，不借首页或其它来源补丁填充。

情境推荐需要核对触发条件。例如“超级暴击”仅为已有技能暴击的友军增加暴击伤害，本身不授予技能暴击；阿兹尔需达到当前裁决使门槛，婕拉则需真实装备或强化效果支持，不能仅凭法系身份判断。阵容与装备候选保留各自来源，临时法杖效果不写成永久羁绊或库存装备。

Agent 先引用法杖效果和选手评级，再按用户给定阵容提供情境建议。临时战斗增益不作为永久阵容羁绊；随机变形结果不当成必得棋子。需要变阵时给出候选队友与少量调整步骤，并注明推演，不声称该法杖阵容有实测胜率。工作台通过原有审核流程才会改变。
