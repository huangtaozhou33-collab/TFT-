## 真实 Embedding 与混合检索

- 模型：阿里云百炼 `qwen3.7-text-embedding`，1024 维，COSINE 索引。
- 先用两条中英文短文本验证接口，再完成 678 个当前补丁合格片段的构建、写入数量与逐 ID 回查。应用容器重建后索引继续可用。
- `node scripts/check-rag-live.mjs --allow-provider`：10/10 通过，Redis 重复查询命中；结构化结果见 [RAG_LIVE_VALIDATION.json](RAG_LIVE_VALIDATION.json)。
- 7 条正例包括普通光明化、超级暴击、六羁绊奖励、第四阶段蓝球、八级商店概率及两条中英文别名。关键条件和概率分支均在返回的同一片段内；蓝球返回真实图片引用，所有证据属于 18.4。
- 蓝球与八级商店概率的目标片段均位于返回第 1 位；普通版超级暴击目标片段在第 2 位，基础版和升级变体仍是不同实体。
- 首轮 8 例中无关烹饪题误返回云顶资料。修复后，烹饪、天气和护照 3 个无关问题都返回 `hybrid/not_found`、空证据，未以词法降级重新引入噪声。
- 当前 COSINE 下限为 0.5。小样本测量中，3 条无关问题的最高分约 0.30～0.37，知识与别名正例约 0.73～0.89；两条额外口语云顶问题约 0.57～0.64。该值只作为这套模型和语料的初始相关度过滤，不是事实置信度。明确实体、完整别名和完整标题匹配保留；改变阈值会隔离缓存，不改变向量索引。

真实 `POST /api/chat` 测试问题为“我升到八人口以后，商店每个格子出现四费棋子的机会是多少？”。聊天入口返回 **4 费 30%**，说明是单格费用概率而非指定英雄概率，并引用商店概率资料 `[S3]`。返回的 knowledge 证据关联本次发布、切片与补丁；原始验收记录见 [RAG_CHAT_VALIDATION.json](RAG_CHAT_VALIDATION.json)。

基础 `check:storage` 显式禁用它自身的模型调用，本轮返回 `embeddingProviderCalled: false`；即使应用已接通真实索引，该脚本仍只验证基础设施，不产生模型费用。
