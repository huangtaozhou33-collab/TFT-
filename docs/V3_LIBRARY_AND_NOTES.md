# V3 资料库识图与个人笔记首页

资料库的「赛季特殊玩法」现在统一包含「法杖出现条件」「法杖图鉴」「机制细则」。默认先查出现条件：卡片直接显示费用、精确回合窗口、再次出现冷却及特殊限制摘要；详情优先展示完整出现条件、模式、互斥强化和来源差异，再显示效果触发。可以按回合、分类、形态和收录状态筛选，也可以在资料库首页或全站搜索中查法杖名称、金币／生命等限制以及互斥强化。原 `#wisp-rules` 链接仍能进入统一模块的机制细则。

当前使用已核验的 Little Buddy Bot 18.4 条件表及 Riot 18.4 更新说明，覆盖 343/349 个法杖／变体。6 个形态缺少条件，不继承其他形态的数据。回合筛选同时保留官方与来源表的争议边界，标为来源差异；只表示窗口匹配，不保证出现在商店。冷却单位是「被提供后经过多少个法杖商店」，不是购买后经过多少个回合。

「战利品法球」新增灰、蓝、金、棱彩四种真实图标，点击图片后只列该颜色的阶段表。奖励行展示弈子费用图标、金币、复制器、锻造器、拆卸器、重铸器与已有装备图鉴图片。系统专题列表也增加法球缩略图，资料库首页提供识图入口。有关联图鉴的专题展示实体图标，来源图表保留在「图片对照」中；主要内容仍是可搜索的中文原生表格。

图标通过 CSS 窗口展示未经修改的已核验源图，没有把图里的英文表头和数量作为中文 UI。原图保存在 `public/assets/library/loot-orbs-set18.png`，来源、采集日期及 SHA-256 保存在同目录的 `sources.json`。文件名补丁提示、图内日期和资料来源补丁独立记录；图片不是游戏补丁已核验的证据。

阵容规划器默认进入个人笔记首页，按最近更新时间展示实际保存的笔记、补丁标签、英雄图片、关注项数量和文字摘要；支持名称／英雄／摘要搜索及版本筛选。新增、打开笔记、带入来源阵容或导入 JSON 后进入编辑页。保存成功返回列表，编辑页可以返回；未保存修改仍需在原有弹窗中选择保留或放弃。

新笔记优先使用已核验游戏补丁，没有时采用当前机制资料补丁（目前 18.4）作为可编辑的个人标签，保存其来源类型。旧笔记没有标签时显示「版本未记录」，浏览和导入不会自动补成 18.4。个人标签不改变全局游戏补丁、统计口径或资料目录兼容检查。

保留原 localStorage 键 `tft.atelier.teamnotes.v2`，兼容读取存储包 v2，首次实际保存／恢复／删除时才写存储包 v3，防止旧标签页把新增的版本字段抹掉；单份笔记 JSON 和棋盘格式仍为 v2，增加可选 `versionTag`。原有英雄、站位、装备、星级、关注项、来源快照和时间不因浏览而改写，删除仍可从回收站恢复。

验证包含多份笔记的独立版本、旧存储包只读迁移、JSON 往返、回收站恢复、无效标签拒绝、法杖回合边界与未知形态、条件搜索，以及图标文件哈希和区域范围。浏览器验证实际已有笔记、新增页、法球图片与阶段切换、法杖搜索和详情，覆盖白天／黑夜显示。
