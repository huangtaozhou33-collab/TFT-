# V3 显示模式与版本栏

2026-10-08 的视觉更新参考了以下获奖作品的留白、字体层级、对比和克制的交互。界面使用本项目的原生 HTML/CSS，没有复制参考网站的代码或图像。

- [Lusion 官方网站](https://lusion.co/)及[官方介绍与获奖记录](https://lusion.co/about/)：清晰的标题、宽松的版面、圆角大块区域与集中的强调色。
- [Non-Linear Studio · Awwwards](https://www.awwwards.com/sites/non-linear-studio)：获 2024-08-06 Site of the Day；参考黑白对比、文字节奏与清楚的索引关系。

白天采用暖白背景、深绿文字及浅绿强调；黑夜采用炭黑背景、暖白文字及亮绿强调。资料库、阵容首页、个人规划器、大数据、开发者模式、弹窗和助手共用颜色角色；英雄费用与游戏图像保留本来的含义。白天的单色羁绊图标改为深色，避免白色图标淹没在浅色背景中。

顶部的“白天／黑夜”按钮立即切换并保存在 `tft.atelier.theme.v1`。首次访问按系统偏好选择；用户选择后按保存的设置显示。外部 `theme-init.js` 在样式加载前应用主题，符合现有仅允许本站脚本的 CSP。多个标签页同步主题，系统偏好变化只影响尚未手动选择的用户。存储不可用时仍可以在当前页面切换。

常驻版本栏突出显示应用 `V3.0.0`、赛季 `S18` 与机制资料来源补丁 `18.4`，所有页面都能看见。版本详情分别列出游戏补丁、机制资料、资源版本、统计补丁；来源中的数字不会被借来补全未知游戏版本。目前目录没有已核验的游戏补丁，因此显示“游戏补丁待核验”。部分规则条目仍为旧版或待核验资料，具体适用性以条目标记为准。

`public/theme.css` 定义两套颜色角色和版式；其他样式使用同一套变量。`appearance.js` 负责主题控制与独立版本语义。切换主页面会回到顶部，专题列表的固定位置避开版本栏。小屏幕保留两种主题按钮与主要版本信息；减少动态效果的系统设置会取消卡片位移动效。

验证包括主题切换及刷新记忆、实际浏览器中的表格／弹窗／棋盘／助手配色、版本弹层、版本语义测试和项目测试。可见正文与表格的颜色对比另行检查；不将该检查声称为全站无障碍认证。
