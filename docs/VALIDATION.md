## 当前数据与明确边界

当前上下文为国际服 TFT Set 18、CommunityDragon 固定资产版本 16.20；规则版本为 `set18-assets16.20-recipes18.4-v4`。装备响应 18.4 不充当阵容或英雄统计补丁。

实际覆盖 74 条英雄/形态、137 件装备、35 羁绊、249 强化符文、55 已核验配方。74 条含拉克丝形态，不能当成 74 个独立商店英雄。39 件普通成装可自动分配，88 件特殊装备的兼容性仍未核验，保留库存。未识别职责属性不自行猜测。

死亡之蔑已从 OP.GG 当前 Set18 装备表补入图鉴。其 ID 与源明确别名均不在实际持有者工具的 enum 中，因此该件装备统计显示“来源暂不支持”；这不能证明 OP.GG 内部没有统计。31 件神器中30件持有者查询已入库，未用其他装备替代缺项。

技能动态变量、统计补丁、地区、段位、时间窗口与部分样本口径没有来源值时保持未知。规划给出可核对的资源方案，不能推出队伍胜率最优或提升幅度。

本版有原创通用学习笔记与来源阶段棋盘示例，尚无经过审核的阵容运营/转型模板；个人战绩与排行榜也未接入。第三方统计的公开商业展示、缓存与再分发许可尚未确认。当前交付在本机运行，没有发布到公网。

## 使用

双击项目根目录的 `start.cmd` 或运行 `npm start`，打开 <http://127.0.0.1:3000>。密钥继续保存在本机 `.env`；修改 API 配置会在下一次请求读取，端口更改需要重启服务。

自动草案与收藏存放在使用该网页的浏览器 localStorage；换浏览器不会共享。完整说明见 [README.md](../README.md)。
