## 别人启动后能得到什么

| 功能 | 条件与边界 |
|---|---|
| 图鉴、规划器、资料浏览 | 无模型Key即可运行；图片仍可能依赖外部来源 |
| MySQL与Redis | Docker首次启动执行迁移和种子导入；不会复制开发者数据库 |
| MetaTFT实时统计 | 需要网络及来源接口可用，按开发者页面同步；仓库种子不是完整MetaTFT数据库备份 |
| AI问答 | 用户自行配置兼容聊天服务和Key |
| Milvus语义召回 | 启动RAG服务、配置Embedding并显式建索引；不随Git复制本机向量卷 |
| 自动更新 | 应用持续运行才执行，来源失败保留旧结果；非离线保证 |
| 私人笔记 | 浏览器本地保存，换端口、浏览器、机器需导出导入 |
